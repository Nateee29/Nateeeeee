Import your CSV files

Export Google Forms responses as CSV. Import your invited guest list first, then import the RSVP responses. Existing records are updated rather than duplicated.

1. Invited guest list

CSV should contain a column for the guest's full name. Recommended header: Full Name.

2. Google Forms RSVP responses

CSV should contain the respondent's name and RSVP answer. Recommended headers: Full Name and Attendance.

Important: Header names are detected automatically for common labels such as Name, Full Name, Guest Name, RSVP, Attendance, and Will you attend. If a response name does not exactly match one invited guest, it will be skipped and reported for manual review. This avoids assigning an RSVP to the wrong person.
